# Sail

**Status: discovery, not a released product.**

Sail is a proposed managed integration layer for businesses to offer governed customer transactions through compatible AI assistants. The product thesis, customer willingness to pay, supported channels, and architecture have **not** been validated.

## First milestone

Before building another landing page, validate the buyer, painful workflow, alternative solutions, and recurring reason to purchase. Do not import the old Sail v1–v4 designs as approved direction.

## Start here

Read [AGENTS.md](AGENTS.md) and [CODEX_START_HERE.md](CODEX_START_HERE.md). Work on dedicated branches and open reviewable pull requests. Research and strategy come before mockups and frontend code.

No simulated customer logos, revenue, integrations, security certifications, user research, or agent executions should be presented as real. The Sail name remains a working name and is not trademark-cleared.
