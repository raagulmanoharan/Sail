# Designer flow revision

Rebuilt by the graphic designer after independent critique. The screen now uses a quiet systems strip, one numbered Sail workflow and a larger persistent assistant phone. Looped connector borders and redundant card examples have been removed.

Motion follows one document workflow: request signal reaches Sail; illustrative POST /documents returns a receipt; the branded Willow component updates; the adapter carries the result into the assistant; the phone reveals confirmation only on arrival. The clinic workflow persists until the diagram exits. Booking restores during the following transition. Narration and the full composition duration remain unchanged.

The architect approved this as a conceptual architecture illustration. API endpoints are examples, not deployed product claims. MCP Apps / Apps SDK support varies by host; the screen explicitly limits its compatibility wording to supported hosts. Document receipt does not mean clinical approval.
