## Continuous composition architecture

Use ONE persistent phone node and ONE service-card shell. Do not allocate a full phone per beat. A parent camera group may translate and scale these together, but phone and screen must stay rigid. A separate business system board and route layer exist throughout, initially hidden beyond the camera view. Bring them into view at 31 seconds rather than swapping canvases. The sole card shell changes state through positioned, clipped content regions: header, image, fields, action, outcome. State transitions hide only content that changes. Keep width, border and anchor positions continuous.

Object lineage: request → typing dots → hotel recommendation → branded service → chosen room/date/total → explicit confirmation → receipt → additional service actions → tokens from existing system → Sail hub → assembled branded component → same conversation → customer outcome. Every new visual is produced by a previous visual. Generic hero entrances are not permitted as the main motion mechanism.

## Practical restraint

Keep existing coherent room/coast SVG illustration style rather than mixing cheap stock photos or generating assets. Enlarging an illustration does not make a mechanism; use masks, drawn outlines, count/value changes, progress, assembly and trace paths. No ambient rotating orbit or background drift per scene; static pale background lets actual action read. Use 0.2–0.45s for UI reactions, 0.7–1.0s for camera changes, 0.6–1.2s holds for important data. Avoid large perspective rotations, elastic overshoot and continuous wobble. Subtitles may remain in a single stable bottom region; never restart the phone with each caption.

A user-visible capture must show: one recommendation becoming one branded interactive card; one explicit total and confirmation; three non-booking actions; a business-system token crossing Sail and becoming usable UI; unchanged assistant chrome with brand variation. If any are missing, adding more entrance animations cannot fix the explanation.

## Implemented rebuild

One persistent phone and service shell replace the overlapping scenes. Date and price changes, ordering, seat selection and upload progress demonstrate actions. A continuously drawn circuit and travelling data tokens connect business systems through Sail to the same assistant. Confirmed booking state stays synchronized. The ending expands to a branded catalogue order. Captions hold a fixed baseline and bridge brief speech pauses.

Independent agent review found no critical remaining geometry or state defect in sampled frames and source. The reel is exported at 60fps.
