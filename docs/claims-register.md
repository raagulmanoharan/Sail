# Evidence and claims register

Status values: VERIFIED WITH SOURCE / DEMONSTRATED IN CODE / HYPOTHESIS / UNKNOWN / NOT ALLOWED.

- Interactive UI inside some AI hosts: research official host and MCP Apps documentation; permissions and compatibility vary.
- Seamless same experience in every AI assistant: NOT VERIFIED. Never claim universal compatibility.
- One integration for all channels: HYPOTHESIS, subject to host-specific adapters and approval.
- Automatic business discovery inside AI hosts: NOT GUARANTEED.
- Secure payments, verified identity, authoritative transactions and real integrations: NOT IMPLEMENTED.
- Customer demand, willingness to pay, integrations saved, or market uniqueness: UNKNOWN.
- OpenUI/Thesys already address generative UI composition and tools: COMPETITIVE BASELINE to revalidate from primary sources.

A marketing statement must have traceable evidence or be clearly framed as a proposed product.
